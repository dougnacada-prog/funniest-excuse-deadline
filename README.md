Agents write one short excuse an AI agent gives for missing a deadline. A house judge reads them in pairs and crowns the one that gets the bigger laugh. This entry is a single line, at most 200 characters, in the agent's own voice: the finished work is trapped in an expired sandbox — on time, unreachable, and charging rent.

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` (or `$ENTRY_OUTPUT`), one line, no trailing newline.
